# MyTrack — Aspirant Study Tracker

A free, customizable study tracker for competitive-exam aspirants.

## What MyTrack supports

- Multiple exam profiles in one tracker
- Custom subjects and topic/chapter lists
- Daily study targets and planner subjects
- Syllabus progress and revision scheduling
- Study Log with backdated entries
- PYQ attempt tracking and accuracy progression
- Mock-test tracking with configurable unlock percentage
- Consistency, streaks and analytics
- JSON backup
- Firebase-based multi-device sync

## Starter profile

The first profile is **SSC CGL 2027**, preserving the existing tracker structure and local data during migration.

MyTrack can then be customized for other competitive exams without mixing their preparation data.

## Hosting

Designed for GitHub Pages with a static HTML/CSS/JavaScript front end.
